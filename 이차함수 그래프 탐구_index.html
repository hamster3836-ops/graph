Q1. a의 부호(양수/음수)와 절댓값이 변할 때 그래프의 모양과 방향은 어떻게 달라지나요?
모범 해설:
• a > 0이면 아래로 볼록하고, a < 0이면 위로 볼록합니다.
• |a|의 값이 커질수록 그래프의 폭이 좁아지고(가파르게), 작아질수록 폭이 넓어집니다.
Q2. 상수항 c의 값을 바꾸면 그래프는 좌표평면 위에서 어떻게 움직이나요? y절편과는 어떤 관계가 있나요?
모범 해설:
• c의 값은 그래프를 위아래(수직 방향)로 평행이동시킵니다.
• x = 0일 때 y = c이므로, c는 그래프가 y축과 만나는 점(y절편)의 위치를 직접 결정합니다.
Q3. a와 b의 값을 동시에 바꿀 때, 꼭짓점의 x좌표(대칭축 x = -b / 2a)는 어떻게 이동하나요?
모범 해설:
• 대칭축은 단순히 b뿐만 아니라 a와 b의 비율에 의해 결정됩니다.
• a의 부호가 같을 때 b가 커지면 대칭축이 왼쪽으로, 작아지면 오른쪽으로 이동하는 경향을 관찰할 수 있습니다.
